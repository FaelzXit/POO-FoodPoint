# Estudos de POO em Python

Repositório criado para praticar Programação Orientada a Objetos (POO) em Python.

## Conteúdos estudados

- Classes e objetos
- Atributos
- Métodos

- Listas de objetos
- `return`
- Herança
- Polimorfismo

## Objetivo

Aprender POO na prática por meio de pequenos exemplos e exercícios em Python.
